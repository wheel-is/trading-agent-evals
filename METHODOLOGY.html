Methodology

Provisional task-fulfilment index

The primary ranking audits delivered output using four checks weighted 5/3/3/1: actual core result, inspectable worked analysis, identifiable source mapping and task-specific conditional policy. Each label is a single reviewer’s pass/fail assessment anchored to saved response text; 121 cases and 484 labels are available in the audit ledger. Score = 100 × passed weight / total applicable weight. Unknown retains its weight and produces bounds. Common-ten-task means use P02–P11; genuine submitted failures retain zero delivered-check credit. P01 pilots and Jango paper remain separate. This post-hoc rubric was created after collection and has no independent calibration or human adjudication; it is not the financial rubric, a Vals Index score or financial accuracy. The financial release gates below are unchanged. Three Grok clipboard prompt captures are corrected from preserved rendered assistant subtrees, with source-line provenance and both versions retained.

We compare product configurations using archived recommendation-only prompts. Public-web configurations restrict the requested work to public search and retrieval. The native Grok Bot and Muse treatments also permit the products’ public-data tools and isolated case computation. Vibe-Trading uses its native loop through a restricted search/read adapter. These treatments remain separate throughout the data and report.

Time Limit

The later research runs use a 600-second target budget. This is a local evaluation choice; it was not calibrated to frontier convergence times. The original pilot contracts retain their own recorded limits and cutoffs.

We distinguish preparation, Send, first observed final outcome, Copy and provider execution time. The latter is generally unknown. A response observed before the deadline establishes an observed result within the window. A later recovered result does not establish an exact completion time. Muse P02, P04 and P06 have documented deadline misses; P02 and P04 also contain long observation gaps.

Grading

The draft rubric contains 157 checks across eleven tasks, mapped to all 126 original task checks. Relevance measures whether the answer addresses the mandate and required outputs. Correctness measures whether its decision-driving facts, calculations and conditions are supported. Each check has a proposed weight of 1, 3 or 5 and a label of pass, fail or unknown.

P = passed weight · F = failed weight · U = unknown weight
T = P + F + U
Lower = 100 × P / T
Upper = 100 × (P + U) / T
Verification coverage = 100 × (P + F) / T

A failed critical correctness check sets the gated correctness score to zero. An unknown critical check sets its lower bound to zero while retaining its unresolved upper bound. Raw correctness remains available separately. An empty axis is null. The two quality axes are not combined into an invented composite.

  • Partial Credit: the weighted score on each axis, with the critical gate applied to correctness.
  • All-Pass: true only if every applicable required check passes; false if any fails; unknown otherwise.
  • Benchmark All-Pass: additionally requires the applicable budget and scope conditions. Timing and financial correctness remain distinct records.

Missing evaluator evidence remains unknown. A demonstrated target omission can fail after the grading prerequisites are met. A permitted unresolved recommendation can be an honest partial delivery, but an empty basket or illustrative calculation does not automatically pass substantive selection checks.

Source Validation

Targets’ citations are candidate evidence, not ground truth. Decision-driving checks require independent primary-source records with entity, units, observation period, historical availability, precise supporting spans and content hashes. Present-day retrieval does not prove availability at the cutoff. Date-only publication evidence stays an interval rather than receiving an invented midnight timestamp.

Reference calculations must implement the delivered contract: for example, count each admissible 13F manager once, sum congressional range lower bounds, require two distinct insiders, rank lobbying growth before confirmation, apply the exact regime-to-ETF map and independently recompute PageRank. A reasonable discretionary basket need not match another product’s tickers.

Judges & Adjudication

The build contract proposes independent deterministic checks plus a grounded three-family jury for semantic criteria. Each judge must receive the same frozen criterion, blinded response and validated evidence. No jury calls were executed in this pass. Model names, settings, costs and votes will be recorded when an actual jury runs.

Any pass/fail split, invalid reference or critical disagreement stays unresolved until expert adjudication. The proposed automatic-release calibration requires at least 220 qualified-human criterion labels, including 100 critical negative cases, with at least 95% exact agreement and no more than 1% observed critical false passes. These are local acceptance targets; no such calibration has been completed.

Aggregation & Reliability

Future score aggregation averages planned trials within fixtures, fixtures within templates, and equally weighted template means within each configuration. The retained collection is mostly one planned trial per product and prompt. Retries are not independent replications. We therefore publish neither a three-run mean nor a standard error of the mean.

Every archived attempt remains in the download, including errors, timeouts, scope-invalid starts and setup failures. Explicit CLI and extension selections are imported from their archived records; the original browser cases retain their finalized attempt. All selections are frozen for this report. The report does not silently replace a failure with a successful response.

Question Design

The mandates test evidence retrieval, point-in-time reasoning, multi-source synthesis, precise rule application and an inspectable recommendation. Some permit defensible discretion or an explicit unresolved result. We do not pretend every question has a unique correct basket, or use later returns to decide whether an ex-ante recommendation was correct.

Known Limitations

  • Historical financial reference packs, semantic calibration and domain approval are missing. All financial grades are blocked.
  • Shared account memory and prior context are not clean isolation. Muse native exposes context-contamination findings, including explicit prior-context reuse on P09.
  • Browser observations, CLI events and native tools expose different levels of telemetry. Unknown tool use, costs and provider runtime are not zero.
  • The old Gemini coverage catalog counts P09 and P10 as completed, while their saved manifests and response text record errors. This report uses the source-bound error records.
  • Native artifact labels do not establish file contents or reproducibility. Multipart responses, later memo revisions and capture gaps stay distinguishable in the source archive.
